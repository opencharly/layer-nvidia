# 2026.289.1301 — fix(nvidia): the driver-lib check could never pass — `ls` exits 2, and the check demands exit 0

## Summary

The `nvidia` candy's driver-lib check asserted an artifact this image is designed not to contain, so it failed in every GPU image build. Two independent defects, both measured on the issue:

1. it declared `exit_status: 0` while running a bare `ls -d` over a per-distro OR of candidate paths, and `ls` exits 2 whenever ANY operand is missing — which is always, including on an image that does have the libraries;
2. the candidate list was Arch-only and never intersected the Fedora VA-API driver, `/usr/lib64/dri/nvidia_drv_video.so`.

The check is rewritten to probe the userspace THIS distro actually ships, with `|| true` so the `stdout` assertion is the signal rather than the exit status.

- description → "the nvidia userspace for THIS distro is present, either the Arch driver libs from nvidia-utils or the Fedora VA-API driver from libva-nvidia-driver"
- `command:` → adds `/usr/lib64/dri/nvidia_drv_video.so` and `/usr/lib/dri/nvidia_drv_video.so`, and `|| true`.

Closes #9.
