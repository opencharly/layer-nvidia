# 2026.245.1541 — fix(nvidia): make the two baked checks arch-family robust (command-level)

## Summary

The hybrid-gpu bed (check-omarchy-hybrid-gpu-vm) composes this layer on omarchy, where two baked checks break:

1. `nvidia-container-toolkit-gpgcheck-enforced` ran despite its `exclude_distro` list — the check runner does not honor that field (verified on live runs: it executes on omarchy, an excluded arch-family guest). The check failed on the Fedora-only DNF setopt path. Fix: implement the arc-family exclusion IN THE COMMAND — when `/etc/dnf/repos.override.d/99-config_manager.repo` is correctly absent (arch-family), exit 0; when present (fedora), keep the `gpgcheck=1` assertion.
2. `plan-step (LD_LIBRARY_PATH)` asserted an RPM-only env export (`printenv LD_LIBRARY_PATH` containing `/usr/lib64`) — the omarchy arm installs nvidia-utils whose driver libs land under `/usr/lib` (arch layout; `/usr/lib64` is the compat symlink), and the export does not land in the check's non-login shell. Fix: assert the driver-lib directory exists, accepting both layouts (`/usr/lib64/nvidia`, `/usr/lib/nvidia`, `libnvidia*`).
