# 2026.245.1450 — fix(nvidia): add omarchy distro arm + scope the gpgcheck assertion off arch-family guests

## Summary

`layer-nvidia` only declared `arch` + `fedora` distro arms. The L3 hybrid bed (`check-omarchy-hybrid-gpu-vm`, distro-omarchy) composes this layer on omarchy (an Arch-family distro), where two baked checks break:

1. `nvidia-container-toolkit-gpgcheck-enforced` asserts gpgcheck=1 by awk-ing `/etc/dnf/repos.override.d/99-config_manager.repo` — a Fedora-only DNF path. The check's own comment declares it Fedora-scoped and already carries `exclude_distro: [arch, cachyos]`; **omarchy was missing from that list** (the layer predates the distro), so the check ran on omarchy and failed with `awk: fatal: cannot open file ... No such file or directory` (verified on the bed, calver 2026.245.1437).
2. The layer had no `omarchy` distro arm at all — so no package arm existed for the composed guest beyond the shared `nvidia-container-toolkit`.

**Changes:** add the `omarchy` distro arm (`package: [nvidia-utils]`, mirroring the arch arm — the omarchy extra repo ships nvidia-utils), and add `omarchy` to the gpgcheck check's `exclude_distro` list (same rationale as the existing arch/cachyos entries). Schema stamp migrated 2026.232.0520 → 2026.240.1943 (current floor).
